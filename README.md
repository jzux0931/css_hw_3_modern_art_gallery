# Conquerblocks CSS HW 3 - Modern Art Gallery

Responsive landing page project for Conquerblocks CSS module.  
This project recreates a modern art gallery website with a Home page and a Location page.

## Features

- Semantic HTML structure
- Mobile-first responsive design
- Home page and Location page
- Responsive layout for mobile, tablet, and desktop
- Sass/SCSS architecture
- CSS custom properties
- CSS Grid gallery layout
- Vite development environment

## Technologies

- HTML5
- Sass/SCSS
- CSS Grid
- CSS custom properties
- Vite

## Pages

- Home page: `index.html`
- Location page: `location.html`
